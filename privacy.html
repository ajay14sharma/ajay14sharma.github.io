Privacy Policy — Delta Edge

Formerly known as Delta Exchange Fee Calculator v3.0.0
Last updated: November 18, 2026
Executive Summary: Delta Edge is a privacy-first browser extension designed for traders on Delta Exchange. All core financial computations—including real-time maker/taker fees, 18% Indian GST separation, Black-Scholes Greeks, and SL/TP payoff simulations—run 100% locally on your machine. We never collect, transmit, or store personal information, trading balances, order amounts, passwords, API keys, or private wallet keys. To help us understand which features are most useful, the extension collects strictly pseudonymous, aggregated feature adoption events (via Google Analytics 4), which users can opt out of with a single click at any time in the extension settings.

1. Single Purpose & Product Identity

The single purpose of the Delta Edge extension (Chrome Web Store ID: kjmpmihngnckancnmiikpjhfdbginpgi) is to enhance trading transparency on Delta Exchange (https://india.delta.exchange and https://www.delta.exchange). It provides real-time maker/taker fee breakdowns, 18% Indian GST isolation, multi-expiry risk filtering, and institutional options payoff charts directly within the trader's interface.

2. Data Collection & Non-Collection Scope

We adhere to strict data minimization principles. Delta Edge:

  • Does NOT collect any Personally Identifiable Information (PII) such as your name, email address, phone number, physical address, or IP address.
  • Does NOT collect, ask for, or store trading passwords, API keys, private keys, or wallet credentials.
  • Does NOT track or inspect user account balances, trade quantities, margin details, or actual execution prices.
  • Does NOT track user browsing activity, search history, or keystrokes outside of the active Delta Exchange tab.
  • Does NOT use advertising trackers, cross-site cookies, or fingerprinting scripts.

3. Chrome Permissions & Host Access Justification

Delta Edge requests only the minimal permissions strictly required to execute its core trading analytics features:

Permission Type Technical Purpose & Justification
https://*.delta.exchange/* Host Permission Strictly limited to official Delta Exchange domains. Used exclusively to:
1. Inject fee columns, Greeks badges, and filter chip controls into the open Positions / Risk View table.
2. Query Delta's authenticated REST endpoint (/v2/fills) directly from your active session to look up execution fees for your open contracts.

4. Client-Side Processing Guarantee

All trading and pricing logic in Delta Edge executes 100% client-side inside your browser:

  • All fee calculations, Black-Scholes Greeks formulas, and SL/TP payoff simulations run locally in the browser's JavaScript engine.
  • Network requests to Delta Exchange's API (/v2/fills) originate directly from your browser to Delta Exchange's official servers—no intermediate proxy or developer server is ever used.
  • The extension does not maintain any custom backend servers, user databases, or credential storage.

5. Anonymized Feature Usage Telemetry (Google Analytics 4)

To understand how traders use Delta Edge and identify areas for improvement, the extension collects strictly pseudonymous, aggregated feature adoption signals via the Google Analytics 4 (GA4) Measurement Protocol:

  • What is Collected: Generic, non-personal user interaction events (such as opening the Smart Payoff Studio, applying an SL/TP preset, clicking the scenario matrix, toggling GST mode, or extension version updates).
  • Pseudonymous Identifier: A randomly generated UUID client_id is generated locally in your browser (chrome.storage.local) to group feature usage anonymously. This identifier is never linked to your identity, IP address, Google account, or Delta Exchange account.
  • Zero Financial or Credential Data: Telemetry payloads strictly exclude trade sizes, dollar amounts, strike prices, account balances, or any identifying exchange data.
  • Data Processor: Telemetry is processed by Google Analytics (Google LLC) under standard data processing terms solely for aggregate metrics (Measurement ID: G-CEEBTX1158).
  • Full User Opt-Out: You can disable feature telemetry at any time. Simply toggle off "Anonymous Telemetry" in the extension popup settings or during initial setup on welcome.html. When opted out, all telemetry dispatch is immediately halted.

6. Data Retention, Storage & Cache Eviction

To prevent redundant API queries and avoid hitting rate limits, recently fetched execution fills are cached locally in your machine's browser memory (localStorage and chrome.storage.local):

  • Retention Period: Fill cache entries are retained only while a trading position remains active. When a position is closed or expired, cached fills for that instrument are automatically deleted.
  • Manual Eviction: Users can instantly clear all cached fills at any time by clicking the [✕] flush action inside the extension's popup dashboard.
  • Uninstall Deletion: Removing the extension immediately purges all stored preferences and cache from your device.

7. Data Sharing, Transfers & Third-Party Disclosure

We maintain an affirmative zero-transfer and non-monetization policy:

  • No Third-Party Sharing: We do not sell, rent, lease, transfer, or share user data with any third party, commercial broker, or advertising network under any circumstances.
  • No Monetization of User Data: User data is never monetized, traded, or used for credit, lending, or profiling.
  • No Cross-Context Tracking: The extension cannot and does not monitor any web pages or applications other than Delta Exchange.

8. User Data Rights & Revocation Controls

You maintain full control over your data and extension operations at all times:

  • Opt Out of Telemetry: Toggle off the "Anonymous Telemetry" switch in the extension popup to instantly stop all event reporting.
  • Disable Extension: Toggle the master switch off in the extension popup to instantly revert to Delta Exchange's default interface.
  • Clear Cache: Click the "Cached Fills" [✕] button in the popup to wipe all cached execution fills.
  • Complete Removal: Right-click the extension icon in Chrome and select "Remove from Chrome..." to permanently delete the extension and all associated local data.

9. Policy Revisions & Updates

If our data handling practices change in future releases, this policy will be updated with an updated revision date. Any material changes will be accompanied by in-product release notes.
